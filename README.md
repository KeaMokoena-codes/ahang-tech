# AhangTech 

**An Integrated Full-Stack ConTech Suite for Site Logistics, Reporting, and Procurement.**

AhangTech is a full-stack Web Application designed to bridge the operational gap between physical construction sites and digital management. By unifying asset tracking, daily site reporting, and material estimation into a single web dashboard, AhangTech eliminates site data fragmentation and enforces real-time accountability.

---

## System Architecture & Vision

In traditional construction, site logistics rely heavily on manual tracking (paper logs, whiteboards, or informal messaging apps). This leads to lost tools, missing progress logs, and inaccurate material orders. **AhangTech** replaces these disconnected manual workflows with a unified, three-tier web platform.


```

┌─────────────────────────────────────────────────────────┐
│               Frontend (Web Dashboard)                  │
│       React / Vue OR Jinja2 + Tailwind CSS UI           │
└───────────────────────────┬─────────────────────────────┘
│ HTTP REST API (JSON)
┌───────────────────────────▼─────────────────────────────┐
│                 Backend API (FastAPI)                   │
│   Modular Routers: Asset Manager | Reporter | Estimator │
└───────────────────────────┬─────────────────────────────┘
│ SQLAlchemy ORM
┌───────────────────────────▼─────────────────────────────┐
│           Relational Database (SQLite/PostgreSQL)      │
└─────────────────────────────────────────────────────────┘

```

### Core Modules
1.  **Asset Manager (Active Focus):** Real-time chain of custody tracking for tools, safety equipment, and machinery with automated personnel attribution.
2.  **The Reporter (Upcoming):** Automated daily log generator integrating site attendance, safety incidents, and external weather API data.
3.  **The Estimator (Upcoming):** Material procurement calculator incorporating real-world environmental waste and breakage factors.

## Tech Stack

* **Backend:** Python 3.x, FastAPI, Pydantic, SQLAlchemy ORM
* **Frontend:** HTML5/CSS3, Tailwind CSS, JavaScript (React / Vue or Jinja2 + htmx)
* **Database:** SQLite (Development) / PostgreSQL (Production)
* **API Documentation:** OpenAPI / Swagger UI (Auto-generated by FastAPI)

## Asset Manager API Endpoints (Phase 1 MVP)

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/assets` | Retrieve all site assets and current statuses |
| `POST` | `/api/assets` | Register a new tool/equipment item |
| `PUT` | `/api/assets/{id}/checkout` | Assign tool to a specific worker |
| `PUT` | `/api/assets/{id}/checkin` | Return tool to available inventory |

## Getting Started

### Prerequisites

* Python 3.8+ installed
* Node.js (if using React/Vue frontend)

### Backend Setup

1. Clone the repository:
```bash
git clone [https://gitlab.com/your-username/ahangtech.git](https://gitlab.com/your-username/ahangtech.git)
cd ahangtech

```


2. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

```


3. Install dependencies:
```bash
pip install -r requirements.txt

```


4. Start the backend server:
```bash
uvicorn backend.main:app --reload

```


*Access API Docs at:* `http://127.0.0.1:8000/docs`
